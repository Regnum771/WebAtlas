# K3 — Map Screen Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user chose native execution on 2026-11-12) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The map screen (`/ban-do`) takes the approved analytical look: a 44 px header, a floating contents panel, grouped map tools, a restyled popup, a status bar along the bottom edge with the scale slider, and a `Ctrl K` command palette.

**Architecture:**
- Presenters, stores and queries stay. Only `*.view.tsx` files and styles change, plus new state where a new control needs it (the palette's index, the panel's filter).
- Each converted view's root carries a `data-slot`, so the `legacy-compat` sheet and the legacy style comparison skip it. Its folder is added to Tailwind's `@source` list in `app.css`.
- Legacy CSS for a converted view is deleted in the same task.
- A new container that still holds legacy content (the contents panel around Bản của tôi and the catalogue section; a tool popover around a legacy menu body) carries **no** `data-slot`, so the compat sheet keeps giving that legacy content its browser defaults. Such a container sets `border-solid` itself, because compat reverts preflight's border style on it. Its new children (title row, group bars, layer rows) each carry a `data-slot`.
- The legacy style comparison stops applying to `/ban-do` once the screen converts. It still must show no new differences on `/`, `/du-lieu`, `/ho-so` and `/quan-ly/*` below the header.

**Tech Stack:** as K2, plus shadcn `popover`, `dropdown-menu`, `tooltip`, `checkbox`, `slider`, `command` (cmdk).

**Spec:** `docs/superpowers/specs/2026-11-11-platform-reskin-design.md` ("Visual system", "Surfaces → Map", R7, R8, R9, the K3 row).

## Global Constraints

- Rules from the spec, verbatim: corners 3 px tags/kbd, 4 px buttons/inputs/toolbars, 6 px panels/dialogs; no pill shapes; a 1 px `line` border on every panel; a shadow only on popup, menu, toast; layer rows 30 px, group rows 32 px, controls 28 px in panels and 30–32 px in main bars; body 13 px, panel titles 14 px.
- Banned: pill shapes, iOS switches, segmented tab controls, round avatars, floating action buttons, frosted bars, stat cards.
- **R8:** the bottom edge of the map is the status bar, always. Nothing covers it in any map state.
- **The scale slider keeps the 11 stops of `ZOOM_SCALE_LEVELS`** and the two named stops of `NAMED_SCALES` (cấp vùng 1:250.000, cấp tỉnh 1:100.000). Its model code is untouched.
- Numbers (scale, coordinates, counts) use `font-num`. River names in the popup use `font-water` italic.
- The OSM Carto basemap stays. `MapView` stays a sibling of `<Routes>`.
- Supported viewport: 768 px and wider. Every check runs at 768, 1100 and 1440.
- UI copy stays Vietnamese; existing strings are reused where a control already exists.
- Focus comes only from the global R9 rule. Comments are English; commits are Vietnamese Conventional Commits with the `Co-Authored-By` trailer. No recursive deletes.
- After every `shadcn add`: uninstall the `cn` package and point imports at `@/shared/lib/utils` (the `shadcn.test` guard fails otherwise).

## Decisions This Plan Makes Beyond the Spec

1. **Header colours:** `surface` background, a 1 px `line` bottom border, `ink` text, a 2 px `brand` underline on the active nav item. The green bar goes (R3 lifted that rule). `Button`'s `inverse` variant is removed with it.
2. **Trợ lý stays docked as today** (the dock's own redesign is K4). K3 only moves its button into the new header and adds the `/` shortcut.
3. **The tool menus' bodies are not redrawn in K3.** Measure, analysis area, add-data, basemap and flood keep their current contents, shown in a popover from the new tool buttons. K4 moves analysis results into the dock.
4. **"Profile" and "print" tool buttons** open the existing analysis menu and the `/print` route.
5. **Selection count** in the status bar reads the ROI/selection store that exists today; it shows `0 đối tượng` when nothing is selected.
6. **`verify:shell` is replaced** by a new `verify:map-shell` script for the K3 screen. The old script's five stale checks are dropped with it.

## Review Focus

1. A popover or menu opened near the bottom edge covering the status bar. → Task 7's browser check opens every tool at 768 px.
2. The contents panel's filter hiding every layer with no "no results" line. → Task 4 test.
3. `Ctrl K` or `/` firing while the reader types in an input. → Task 6 tests.
4. A layer limited to certain scales toggled on outside its range, with no hint. → Task 4 test for the scale note.
5. The status bar wrapping or clipping at 768 px with the panel open. → Task 7's browser check.
